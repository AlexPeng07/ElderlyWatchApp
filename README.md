# 银龄智守

**银龄智守**是一款面向独居老人安全守护场景的 Android 手机端应用。它通过经典蓝牙连接守护手环，实时展示健康数据；当手环上报跌倒信号时，应用会在手机上发出震动提醒，并自动向预先设置的紧急联系人发送求助短信。

> 本项目是**手机端配套应用**，不是 Wear OS 手表应用。跌倒识别由已连接的手环负责，应用负责接收信号、展示状态和联动告警。

## 功能

- **蓝牙手环连接**：扫描附近或已配对的经典蓝牙设备，并通过 SPP（RFCOMM）建立连接。
- **实时数据看板**：解析并显示手环上报的心率、体表温度和步数。
- **跌倒自动告警**：收到包含 `FALL` 的上报数据时，界面切换为告警状态、手机按预设节奏震动，并发送求助短信；同一次告警不会重复触发短信。
- **一键紧急求助**：用户可在主界面主动发送求助短信。
- **紧急联系人设置**：可在应用内设置并本地保存短信接收号码。
- **守护参数下发**：可调整心率、温度的上下限，并通过蓝牙将参数发送给手环。
- **连接状态反馈**：区分未连接、正常监控、连接失败和意外断开状态。
- **家属服务入口**：支持配置“家属守护中心”和“守护管理端”地址，并以内嵌网页打开；WebView 会保留登录 Cookie 与本地存储状态。

## 工作流程

```text
守护手环 ──经典蓝牙 SPP──> 银龄智守（手机）
                                  │
                   心率 / 温度 / 步数 → 实时看板
                   FALL 信号        → 告警界面 + 手机震动 + 短信通知
                   参数调整          → 蓝牙命令下发至手环
```

## 手环通信协议

应用使用 RFCOMM UUID `00001101-0000-1000-8000-00805F9B34FB` 连接设备，并按文本片段解析上行数据。当前代码识别如下字段：

| 上行字段 | 用途 |
| --- | --- |
| `$Heartrate:<值>#` | 实时心率 |
| `$Temperature:<值>#` | 体表温度 |
| `$Steps:<值>#` | 步数 |
| `$setHeartMin:<值>#` / `$setHeartMax:<值>#` | 心率阈值回传 |
| `$setTempMin:<值>#` / `$setTempMax:<值>#` | 温度阈值回传 |
| 任意包含 `FALL` 的文本 | 触发跌倒告警 |

下行参数命令以 `\r\n` 结尾，例如 `setHeartMin:60`、`setTempMax:37.3`。手环固件需实现与上述格式一致的通信协议。

## 运行要求

- Android 6.0（API 23）及以上的手机
- 支持经典蓝牙的守护手环
- 可用的短信服务；首次发送时需要在系统中授予短信权限
- Android Studio 与 JDK 8

项目配置：`minSdkVersion 23`、`targetSdkVersion 28`、`compileSdkVersion 28`，使用 Gradle 7.5 和 Android Gradle Plugin 7.4.2。

## 构建与安装

1. 使用 Android Studio 打开项目根目录并等待 Gradle 同步完成。
2. 连接 Android 真机并启用蓝牙。
3. 构建调试包：

   ```powershell
   .\gradlew.bat assembleDebug
   ```

4. 安装生成的 APK：`app\build\outputs\apk\debug\app-debug.apk`。
5. 启动应用后，点击“连接手环”，选择目标蓝牙设备。

## 使用说明

1. 在“设置短信通知号码”中填写 11 位紧急联系人手机号码。
2. 如需要家属网页服务，分别配置“家属守护中心地址”和“守护管理端地址”；仅接受 `http://` 或 `https://` 地址。
3. 连接手环后，主界面显示“状态正常，监控中…”即表示蓝牙连接成功。
4. 手环上报健康数据后，心率、体表温度和步数会更新到主界面。
5. 手环上报 `FALL` 时，应用会自动执行告警流程；也可点击“紧急求助”手动通知家属。

## 权限说明

| 权限 | 用途 |
| --- | --- |
| 蓝牙、位置 | 搜索并连接蓝牙手环 |
| 发送短信 | 跌倒告警和手动求助通知 |
| 振动 | 跌倒告警时提供本机震动提醒 |
| 网络 | 打开已配置的家属服务网页 |
| 外部存储 | 项目当前声明的历史兼容权限 |

## 隐私与安全提示

- 短信接收号码和网页地址保存在本机 `SharedPreferences` 中；请只配置经过授权的家属或监护人信息。
- 本应用会在收到手环的 `FALL` 信号后尝试发送短信。短信能否成功送达取决于系统授权、SIM 卡、运营商和网络状态，应在真实设备上完成演练验证。
- 跌倒检测结果来自手环上报，不能替代医疗诊断或紧急救援服务。建议保留人工确认和其他求助渠道。
- 项目使用较早的 Android API 级别。若面向新版 Android 发布，应补充新版蓝牙运行时权限与通知、短信等相关合规评估。

- 分别测试连接成功、主动断开和超出蓝牙范围后的界面状态。
